# 취업 준비 자동화 시스템

Python 기반으로 취업 준비 업무를 자동화하고, Notion을 운영 화면으로 사용하는 개인 생산성 프로젝트입니다. 이 저장소는 자동화 엔진 역할을 담당하며, 채용 공고 수집, 지원 일정 관리, 리마인더 생성, 맞춤형 추천 로직을 하나의 실행 흐름으로 묶는 것을 목표로 합니다.

## 프로젝트 개요

취업 준비 과정은 공고 탐색, 지원 이력 관리, 일정 점검, 서류 보완, 우선순위 조정 같은 반복 작업이 많습니다. 이 프로젝트는 이러한 반복 업무를 Python 서비스로 자동화하고, 사용자는 Notion에서 전체 현황을 확인하고 운영할 수 있도록 설계되었습니다.

핵심 방향은 다음과 같습니다.

- Notion을 운영 대시보드이자 업무 입력 창구로 사용
- Python 애플리케이션이 자동화 엔진으로 동작
- 공고 수집, 추천, 리마인더, 데이터 저장을 분리된 서비스로 구성
- 이후 실제 외부 API와 스케줄러를 붙일 수 있는 구조로 확장

## 주요 기능

- 채용 공고 수집
  - 다양한 채용 소스에서 공고를 수집하는 서비스 계층 제공
  - 현재는 샘플 데이터 기반 초안으로 동작
- 취업 준비 리마인더 생성
  - 매일 점검해야 할 지원 현황, 마감일, 준비 항목을 자동 생성
- 맞춤형 추천 로직
  - 수집된 공고를 바탕으로 이력서 수정, 우선 지원 대상 선정 등의 액션 제안
- Notion 연동 구조
  - Notion 데이터베이스를 운영 화면으로 사용할 수 있도록 서비스 초안 제공
  - 현재는 실제 API 호출 전 단계의 플레이스홀더 구조
- 로컬 데이터 저장
  - SQLite 기반 저장소를 사용해 실행 기록 및 향후 데이터 적재 기반 마련
- 스케줄 실행 흐름
  - 수집 → 추천 → 리마인더 → Notion 동기화 순으로 실행되는 기본 오케스트레이션 구현

## 시스템 구조

시스템은 크게 두 영역으로 나뉩니다.

- 운영 화면: Notion
  - 지원 현황, 기업 정보, 일정, 추천 결과, 할 일 목록을 확인
  - 추후 사용자가 직접 상태를 갱신하거나 필터링하는 인터페이스 역할 수행
- 자동화 엔진: Python 프로젝트
  - 정해진 주기 또는 수동 실행으로 작업 수행
  - 데이터 수집, 가공, 추천, 리마인더 생성, 저장, Notion 반영 담당

기본 실행 흐름은 다음과 같습니다.

1. 스케줄러가 실행을 시작합니다.
2. 채용 공고 수집 서비스가 공고 데이터를 가져옵니다.
3. 추천 서비스가 지원 우선순위나 준비 액션을 생성합니다.
4. 리마인더 서비스가 일간 점검 항목을 만듭니다.
5. Notion 서비스가 결과를 운영 화면에 반영합니다.
6. DB 계층이 실행 이력과 향후 저장 대상 데이터를 관리합니다.

## 실행 방법

### 1. 가상환경 생성

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```

### 3. 환경 변수 설정

`.env.example`를 참고해 필요한 값을 설정합니다.

예시:

```env
APP_NAME=job-automation-system
APP_ENV=development
LOG_LEVEL=INFO
NOTION_TOKEN=your-notion-token
NOTION_DATABASE_ID=your-notion-database-id
SQLITE_PATH=job_automation.db
REMINDER_HOUR=9
```

### 4. 애플리케이션 실행

```bash
python3 -m app.main
```

실행 시 현재 초안 기준으로 다음 동작이 수행됩니다.

- SQLite 데이터베이스 초기화
- 샘플 공고 수집
- 추천 항목 생성
- 일간 리마인더 생성
- Notion 동기화용 요약 로그 출력

### 5. 테스트 실행

```bash
python3 -m pytest
```
